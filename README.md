# game-workflow

A team of Hermes bots that builds a voxel sandbox game (Minecraft style) with a built-in technology system and magic system.

- `souls/`: one `SOUL.md` per bot (33 bots), the shared `AGENTS.md` for the game project root, and a `README.md` with the roster, lane chats, tool matrix, and setup checklist for botmaker.
- `docs/diagrams/`: the team flowchart and hierarchical mindmap (Mermaid).
- `docs/history/`: earlier drafts, kept for reference. `soul_drafts.md` is superseded by `souls/`.

Start with `souls/README.md`.
